# OG Image Prompts — BATCH 5 (30 articles)

Pinterest-optimized hero image prompts for the BATCH 5 article set. Each prompt follows the Route B template from `pipeline/prompts/03_image.md`: a clean, minimalist Pinterest-style infographic in a vertical 2:3 aspect ratio (**1000x1500 px**), bright but not neon colors, product-focused, no rendered text (text will be overlaid programmatically by `site/scripts/generate-og.ts`), no watermark.

Universal suffix appended to every prompt:

> Vertical 2:3 aspect ratio, 1000x1500 px, Pinterest pin format. Bright but not neon colors. No text, no watermark, no logos. Airy negative space at top and bottom for title and brand overlay. Soft natural lighting, shallow depth of field, product-focused composition.

Paste into Midjourney v7 (append `--ar 2:3 --v 7`), DALL-E 3, Imagen 4, or Stable Diffusion.

## Generation notes

- All 30 prompts target **1000x1500 px** (2:3 vertical) for Pinterest pin spec.
- For Midjourney v7, append `--ar 2:3 --v 7 --style raw` to each prompt for a more editorial look.
- For DALL-E 3 / Imagen 4, request portrait orientation (1024x1536) and downscale to 1000x1500.
- Save raw outputs to `site/public/og/_raw/<slug>.png`, then run the text-overlay build step to produce `site/public/og/<slug>-<locale>.png` per `pipeline/prompts/03_image.md`.
- Quality bar: image < 500 KB, no rendered text, no logos, ample top/bottom negative space for the title and brand overlay.
